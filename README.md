## 👨‍💻 About Me

I'm a **Frontend Engineer and Technical Project Manager** with **3–4 years of professional experience** building and managing web applications, particularly in AI, data analytics, and data-driven product environments.

My experience combines hands-on frontend development with technical project leadership. I've worked on complex dashboards, analytical platforms, web applications, and chatbot interfaces, while also coordinating development teams and managing projects from planning to delivery.

I enjoy understanding how things work under the hood, solving technical challenges, and turning complex product requirements into maintainable and scalable software.

### What I Do

- 💻 Build frontend applications using **Vue.js, Nuxt.js, and Next.js**
- 🏗️ Contribute to frontend architecture and technical decisions
- 📊 Develop analytical dashboards and interactive data visualization interfaces
- 👥 Lead and coordinate development teams, including task planning, prioritization, and delivery
- 🔗 Integrate frontend applications with REST APIs, authentication, and access-control systems
- 🧩 Collaborate with backend teams on cross-layer technical challenges
- 🔍 Review implementations, debug issues, and improve application quality

### Current Focus

- Deepening my understanding of JavaScript fundamentals and internals
- Exploring Vue 3 internals, reactivity, rendering, and component architecture
- Learning React architecture and modern React development
- Improving TypeScript, software architecture, and system design
- Building a stronger engineering mindset through practical projects and technical documentation
